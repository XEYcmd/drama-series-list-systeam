# 作品库做成网站：方案

> 结论：可行，成本 0 元，不用新装运行时（你机器上已有 Python 3.12+），不用公网 IP、不用开路由器端口。
> 本文是方案与验收依据；具体步骤在 TODO 板里，按顺序执行。

## 〇、工作目录（先看这条）

- **本方案涉及的所有代码改动，都在 `本仓库目录\` 里做 —— 改的是副本。**
- `本仓库目录\` 根目录下的 `作品库.html` 等文件是**冻结的离线版**，网站改造期间一个字节都不动。
- 改造前的整份快照：`本仓库目录\备份\作品库-网站改造前-20261005-1544.zip`（含你的 `目前作品.csv` 与 `作品库-基准导入.json`）。
- 副本与冻结版**逐字节一致**（SHA256 相同），`网站版\tests\` 能在副本里独立跑通全部测试。
- 因为页面会按 `file://` / `http(s)` 自动切换存储方式，网站版**双击打开时仍然完全可用**（走 localStorage）。
  所以将来若不想维护两份，可以随时决定留哪一份 —— 不会有功能死角。

## 一、目标与边界

| 方式 | 地址 | 谁用 | 权限 |
|---|---|---|---|
| 本机双击文件 | `file:///D:/dsh的项目/作品库.html` | 我自己 | 读写（数据在本机浏览器，**保持现状不变**） |
| 局域网 | `http://192.168.x.x:7878`（脚本启动时打印） | 我、家里设备 | 读写（输一次口令，之后记住） |
| 外网 / 朋友 | `https://worklib.你的域名` | 我、朋友 | 我=读写；朋友=**只读** |

- **随用随开**：双击一个启动脚本 → 服务起来 → 关窗口就停，电脑关机网站下线。
- **不改现有规则**：排序、查重、UUID 绑定、四条禁忌全部照旧。
- **不做**：多用户/注册体系、数据库、云托管、把数据交给第三方。

## 二、为什么必须动代码（关键决定）

1. **数据要搬到服务端**。现在数据在浏览器 localStorage 里，按设备隔离：手机打开会是空库。
   服务端存一个 JSON 文件（`server/data/作品库.json`），所有设备读写同一份。
   双击本地文件时仍走 localStorage，**单文件离线使用不受影响**。
2. **只读权限必须由服务端强制**。前端藏掉按钮只是体验，谁都能直接调接口。
   两套口令：`owner`（读写）/ `guest`（只读）→ `PUT /api/db` 没有 owner 口令一律 **403**。
3. **不走端口映射**。家用宽带多为动态 IP 且常在大内网，端口映射不稳定也不安全。
   Cloudflare Tunnel 是**出站加密连接**，不需要公网 IP，自带 HTTPS。
4. **局域网不走隧道**。同一网段直连 `192.168.x.x:7878` 最快，隧道只服务于外网访问。
5. **写盘要原子 + 带版本号**。避免"写一半断电"和"两个设备互相覆盖"（后者给 409 提示，不静默丢数据）。

## 四、接口约定

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | `/` | 无 | 返回 `作品库.html`（页面本身不含数据） |
| GET | `/api/whoami` | 口令 | 返回 `{role:"owner"｜"guest"}`，前端据此切只读 |
| GET | `/api/db` | 口令 | 返回 `{revision, db}` |
| PUT | `/api/db` | **仅 owner** | 请求头带 `If-Revision`；版本不符 → `409` + 最新版本号 |

- 口令放在请求头 `X-Worklib-Token`（页面首次输入后存在本机浏览器）。
- 状态码：`401` 口令错/没给，`403` guest 想写，`409` 版本冲突。
- `X-Worklib-Token` 只在局域网/隧道内传输；外网走 HTTPS 加密。

## 五、安全清单

- 口令只存在服务端 `config.json`，**不进网页、不进 git**（写进 `.gitignore`）。
- 口令用长随机串（≥32 位）；比较用 `hmac.compare_digest`（常量时间，防时序侧信道）。
- 静态资源走白名单，禁止目录穿越；限制请求体大小（防有人往接口灌垃圾）。
- guest 只读：前端隐藏写操作 + **服务端对非 owner 的 PUT 一律 403**（双重）。
- 可选加固：Cloudflare Access 加一层邮箱验证（我会在隧道步骤里给出开关步骤）。
- 风险提示：网站一旦公网可达，就会有人扫到并尝试猜口令 → 别用短口令；服务端会记录失败次数到日志，异常可查。

## 六、随用随开与日常运维

- **启动**：双击 `启动-作品库.bat` → 控制台打印局域网网址（+ 隧道状态）→ 保持窗口开着。
- **停止**：关掉那个窗口（或 `Ctrl+C`），端口立即释放，外网同步下线。
- **开机自启（可选）**：注册成计划任务，登录后自动起；不想要就删掉任务。
- **防火墙**：首次运行 Windows 会弹窗，**只勾"专用网络"**，别勾公用网络。
- **备份**：服务端每次启动自动留快照；另外你仍可随时在网页里「导出备份 JSON」存到别的地方。
- **改口令/换端口**：改 `server/config.json` 后重启脚本。

### 六之二、接入三级域名：两条路线（选一条就行）

> 前提（两条路线都要求）：**你的域名已经接入 Cloudflare，并且状态是 Active**。
> 判断方法：登录 `dash.cloudflare.com`，首页站点列表里能看到你的域名、状态显示 Active。
> 如果列表里没有它：`Add a site` 填域名 → 选 **Free** 计划 → Cloudflare 会给你两条 NS（形如 `xxx.ns.cloudflare.com`）
> → **去你买域名的注册商网站**把域名的 NS 改成这两条 → 等生效（几分钟到几小时）。
> 这一步没做的话，`cloudflared tunnel login` 登录成功也**看不到域名可选**，这是最常见的"登录不上"。

#### 你的情况：`example.com`（DNSHE 免费子域）

这是一个**子域**（父域是 `example.com`，DNS 由 DNSHE 托管），所以不是在注册商改 NS，而是**在 DNSHE 面板里给这个子域填 NS**：

1. Cloudflare 面板 → 你这个域名的「查看您的 DNS 记录」页 → 显示 0 条记录 → **直接点页面底部那个蓝色按钮继续**（不用加 A/CNAME，那些提示是通用建议；等第 4 步的隧道会自动加一条 CNAME）
2. 接着 Cloudflare 会给出**两条 NS**，形如 `xxx.ns.cloudflare.com` / `yyy.ns.cloudflare.com` —— 两条都复制
3. 打开 **https://my.dnshe.com/** → 找到 `example.com` → 点 **Name Servers** 按钮 → 把两条 NS 填进「NS 服务器列表」→ 保存
4. 回到 Cloudflare → 点 **「立即检验名称服务器」** → 等它从 Pending 变成 **Active**（通常十几分钟，Cloudflare 会发邮件通知）
5. Active 之后再往下走路线 A 的第 2–5 步（建隧道 → token → Public Hostname → 手机 4G 验证）

> 子域被委托给 Cloudflare 后，Cloudflare 的 CDN/安全能力**只对这个子域生效**（父域 `example.com` 不归你管，也不受影响）。
> 免费计划支持子域委托（Cloudflare 官方 Availability 表：Free = Yes）。

#### 路线 A（推荐，全程在网页上点，**不需要 `tunnel login`**）

1. `dash.cloudflare.com` → 左侧 **Zero Trust**（现在叫 **Cloudflare One**）→ **Networks → Connectors → Cloudflare Tunnel**
2. **Create a tunnel** → 连接器类型选 **Cloudflared** → 起名 `worklib` → 保存
3. 下一页会给出安装/运行命令，里面有一串 **token**。在电脑上**以管理员身份**打开 PowerShell：
   ```powershell
   winget install --id Cloudflare.cloudflared        # 没装过才需要
   cloudflared.exe service install <粘贴那串 token>   # 装成 Windows 服务，开机自启
   ```
   **更符合"随用随开"的用法**：不要装服务，把那串 token 存到 `网站版\tunnel-token.txt`（一行，只放 token），
   以后双击 **`启动-作品库（含外网）.bat`** 就会「起 Python 服务 + 起隧道」一步到位，关窗口两项一起停。
4. 回到该隧道的 **Public Hostnames** 标签 → **Add a public hostname**：
   - Subdomain: `worklib`　Domain: 选你的域名
   - Service: **HTTP**　URL: `127.0.0.1:7878`
   - 保存（Cloudflare 会自动加好 DNS 记录，不用手动建）
5. 手机用 4G/5G 打开 `https://worklib.你的域名` → 输入 `owner` 或 `guest` 口令。

这条路线的好处：不用命令行登录、不用 `config.yml`、DNS 自动配、隧道常驻（你只要按需启动那个 Python 服务即可）。

#### 路线 B（命令行一条龙，方案原本写的）

```bat
winget install --id Cloudflare.cloudflared
cloudflared tunnel login                    :: 需要浏览器授权并选择域名 ← 你卡住的是这里
cloudflared tunnel create worklib           :: 生成凭据文件
cloudflared tunnel route dns worklib worklib.你的域名
```
然后写 `%USERPROFILE%\.cloudflared\config.yml`：

```yaml
tunnel: worklib
credentials-file: C:\Users\<你的用户名>\.cloudflared\<TUNNEL-ID>.json
ingress:
  - hostname: worklib.你的域名
    service: http://127.0.0.1:7878
  - service: http_status:404
```

运行：`cloudflared tunnel run worklib`（或者双击 `启动-作品库.bat --with-tunnel`，它会顺手把隧道拉起来）。

#### 不用在 Cloudflare 上做的事（省得乱点）

- 不用买任何付费计划（Free 就够）
- 不用开 Cloudflare Access（我们用的是应用自己的 owner/guest 口令，已够用；想要更严可以再叠一层邮箱验证）
- 不用加防火墙/WAF 规则、不用手动建 A/CNAME 记录（第 4 步或 `route dns` 会自动建）
- 子域名必须是 **ASCII**：`worklib` ✓，中文子域名 ✗

## 七、验收清单（对应 TODO 板逐条）

1. 服务端起得来，本机能打开页面；无口令 GET 接口 → 401；owner 能读写；**guest 只能读，PUT 被 403**；重启服务数据还在；路径穿越拿不到东西。
2. 从 `http://` 打开会要一次口令；改动 1 秒内落盘服务端；刷新后数据来自服务端；**双击本地文件仍完全可用**。
3. guest 打开后看不到任何写操作，也看不到 UUID 相关功能（显示/改/对应表/导入）；搜索和"导出作品列表（不含 UUID）"仍可用。
4. 两个标签页同时改，后改的收到"已被别处修改"提示，可一键重新载入，不静默覆盖。
5. 双击 `启动-作品库.bat` 能起服务并打印局域网网址；关窗口后端口释放；防火墙只放行专用网络。
6. `winget` 装 cloudflared → 建隧道 → 绑你的三级域名（**子域名必须是 ASCII，如 `worklib`**）→ 手机用流量打开 HTTPS 能看到库。
7. 服务端里就是那 180 条（规则序、UUID 与基准一致）；朋友只读能看不能改；服务重启、电脑重启后数据都在。

## 八、成本与限制

- **成本 0 元**：Cloudflare 免费计划 + Python 标准库 + 你自己的电脑和域名。
- **限制**：电脑关机 = 网站下线（这是"随用随开"的代价）；家宽上行带宽小，多人同时看会慢（你的库只有几十 KB，无感）；Cloudflare 免费版不保证 SLA。
- **备份提醒**：服务端只有一份 JSON，务必保留"启动自动快照 + 定期导出到别处"的习惯。

### ✅ 第 2 步：网页服务器模式（已完成）

`作品库.html` 会自己判断怎么存数据：

- 从 `http://` / `https://` 打开（= 服务器模式）→ 先要口令，之后读写都走服务端；**本机不留任何数据副本**（见下面"隐私约定"）。

点「取消」时本机那份数据不会被覆盖，页面会告诉你它在哪、怎么找回。

#### 隐私约定（2026-10-05 按用户要求加强）

| 约定 | 实现 |
|---|---|
| 未输入口令前**不显示任何作品** | 401 / 连不上服务器时一律显示空库（不拿本机缓存充数），只弹口令框 |
| 关掉页面**不留数据** | 服务器模式下不往 localStorage 写任何东西；口令只存 `sessionStorage`（作用域=本标签页），并在 `pagehide`（非 bfcache）时清掉 |
| **每次访问都要输口令** | 口令不落盘；关标签页/关浏览器即失效（同一标签页刷新也要重输——这是从严的做法） |
| 老版本残留 | 服务器模式下启动时自动清掉 localStorage 里的 `worklib.v1` / `worklib.token`（老版本写过镜像） |
| 已知取舍 | 服务器没开时网页**什么都看不到**（这是"不留缓存"的代价）；`guest` 直接调 `/api/db` 仍能拿到含 uuid 的原始 JSON（前端不显示） |

#### 局域网连不上时按这个顺序查

1. **服务在不在跑**：那个黑窗口开着吗？用端口扫描工具扫的时候没人在听 7878，当然显示"未开放"。
2. **监听地址**：`诊断-局域网.bat` 会显示监听在 `0.0.0.0` 还是 `127.0.0.1`。后者只有本机能访问 → 把 `server\config.json` 的 `bind` 改成 `0.0.0.0` 再重启。
3. **用哪个 IP**：用 `诊断-局域网.bat` 列出的**默认出口网卡**那个地址（例如 `http://192.168.x.x:7878`）。
   ⚠️ 装了 VMware / Hyper-V / Radmin VPN / 各种虚拟网卡时，机器上会有 `192.168.x.1`、`26.x.x.x` 这类**假的**地址，
   手机是连不上的 —— 别用那些。
4. **防火墙**：Windows 防火墙默认挡入站。双击 `开放防火墙-7878.bat` 加一条只对「专用/域」网络生效的规则。
5. **网络类型**：如果 Wi-Fi 被判定为「**公用**网络」，防火墙对它的入站规则不生效（上面那条规则只覆盖专用/域）。
   到设置 → 网络和 Internet → Wi-Fi → 你的网络 → 网络配置文件类型 → 改成**专用**。
6. **同一个网段**：手机要连**同一个 Wi-Fi**（不是流量、不是访客网络）；路由器若开了「AP 隔离」，设备之间也不能互访。
